# Main Backtest Session History Output

`main.py` can save each Full Trading Session Report into a JSON session history file.

This is reporting/history only. It does not connect to live data, Sierra Chart, CME, a broker, OpenAI, or any external API. It does not create trade signals or real orders.

## Example Command

```powershell
.\venv\Scripts\python.exe main.py --mode demo --scenario bullish --profile apex --session-time 2026-06-26T14:00:00Z --show-session-report --save-session-history
```

## Where History Is Saved

By default, session history is saved here:

```text
reports/session_history.json
```

You can choose another folder:

```powershell
.\venv\Scripts\python.exe main.py --mode demo --scenario bullish --profile apex --save-session-history --session-history-dir reports/history_tests
```

## Showing A Summary

Use:

```powershell
--show-session-history-summary
```

The terminal prints:

```text
Backtest Session History
- Saved: True or False
- History path: ...
- Total sessions: ...
- Executed sessions: ...
- Blocked sessions: ...
- Common blocking reasons: ...
- Reasons: ...
- Warnings: ...
```

When `--save-session-history` is used, the summary is printed after saving.

## Why Blocked Sessions Matter

Blocked sessions show when the system avoided poor conditions. A blocked setup may reveal high spread, bad session timing, news risk, invalid risk, weak alignment, or missing confirmation.

Keeping blocked sessions in history helps review whether the safety system is doing useful work.

## Research Only

Session history is for review and research. It only stores reports generated by the paper/demo/backtest system. It is not trading logic and does not create trade signals.
