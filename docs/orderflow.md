# Order Flow / Footprint Analysis

This guide covers the planned research-first order flow and footprint module.

## Planned Features
- Import footprint data from CSV
- Analyze bid volume and ask volume
- Calculate delta and cumulative delta (CVD)
- Detect imbalance
- Detect absorption
- Detect exhaustion
- Build volume profile
- Identify Point of Control (POC)
- Calculate Value Area High and Value Area Low
- Study session volume behavior

## Beginner-Friendly Explanation
Order flow studies the buying and selling pressure behind price movement. It helps the user understand whether price is being pushed by aggressive buyers or sellers.

## Research Use
This module is intended for research and study only. It will not be used for live trading in the current phase.
