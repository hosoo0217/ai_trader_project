# Methodology

This document outlines the research-first methodology behind the AI Trader Project.

## Core Principles
- Backtesting first
- Paper trading first
- No live trading yet
- No broker connection yet
- Beginner-friendly explanations

## Workflow
1. Load historical market data from CSV
2. Apply technical and structural analysis
3. Generate a research signal
4. Evaluate the signal with risk rules
5. Record the decision and outcome
6. Explain the trade or no-trade decision to the user

## Research Focus
The project is designed to help a user learn how markets behave before moving into any live execution environment.

## Learning Goal
The system should teach the user why a decision was made, why it worked or failed, and what lesson to take forward.
